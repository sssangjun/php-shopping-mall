# PHP 게임 쇼핑몰

PHP와 MariaDB를 사용한 학습용 개인 쇼핑몰 프로젝트입니다. 게임 상품 목록과 상세 화면, 회원, 장바구니, 주문 및 관리자 화면을 포함합니다.

## 구성

- `main.php`: 메인 상품 화면
- `product.php`, `product_search.php`: 상품 상세 및 검색
- `member_*.php`: 회원가입, 로그인, 회원정보 관련 화면 및 처리
- `cart.php`, `order*.php`, `jumun*.php`: 장바구니, 주문 및 주문 조회
- `admin/`: 회원·상품·주문 관리
- `css/`, `js/`, `images/`, `product/`: 스타일, 스크립트 및 이미지
- `database/shop47.sql`: 학습용 DB 구조와 가상 데이터
- `juso/`, `sj/`: 주소록·성적 관리 학습 코드

## 사용 기술

PHP, MariaDB/MySQL, HTML, CSS, JavaScript, Bootstrap

## 로컬 실행

1. PHP의 `mysqli` 확장을 지원하는 로컬 웹 서버와 MariaDB/MySQL을 준비합니다.
2. 원본 코드에는 `<? ... ?>` 구문이 있으므로 PHP 설정에서 `short_open_tag=On`을 사용합니다. 일부 `.html`에도 PHP 코드가 있으므로 기존 수업 환경처럼 해당 파일을 PHP로 처리하도록 서버를 설정해야 합니다.
3. 로컬 DB를 만들고 `database/shop47.sql`을 가져옵니다. 이 SQL에 포함된 회원·주문 데이터는 제작자가 가상 학습 데이터임을 확인한 자료입니다.
4. `config/config.example.php`를 `config/config.local.php`로 복사합니다.
5. 실제 로컬 환경에 맞게 DB 호스트, 사용자, 비밀번호, DB 이름과 관리자 계정을 입력합니다. `shop`, `juso`, `sj`, `zipcode`의 연결 설정은 각각 독립적입니다.
6. 웹 서버의 프로젝트 경로에서 `main.php`를 엽니다.

`config.local.php`는 Git 업로드에서 제외됩니다. GitHub에서 새로 내려받은 환경에서는 이 파일을 직접 만들어야 합니다. 예시 파일에 실제 비밀번호를 적어 커밋하지 마세요.

## 데이터 및 실행 범위

- 가상 회원·주문 데이터와 학습용 CSV/TXT 자료를 보존했습니다.
- SQL 백업에 포함되지 않은 우편번호 테이블(`zip1` 등)은 우편번호 검색 기능을 사용하려면 별도로 준비해야 합니다.
- 원본 소스와 화면 자산을 보존하고 DB·관리자 인증 정보만 별도 로컬 설정으로 분리했습니다.
- 이 저장소는 학습 및 포트폴리오용 코드입니다. 실제 결제 서비스 연동이나 운영 환경의 보안 검증을 의미하지 않습니다.
- 상품 이미지 및 외부 라이브러리의 권리는 각 권리자에게 있습니다.
